# Security policy

FundGraph Core is a reusable library for parsing dependency and funding evidence. Do not send private source code or credentials to external services through this package.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Use the private security reporting mechanism on the [FundGraph organization security page](https://github.com/FundGraph/fundgraph/security) when available. If private reporting is unavailable, contact the project maintainers through the organization profile and include only the minimum reproducible details.

The project-level security model and residual risks are documented in the `fundgraph` repository's `SECURITY.md` and `SECURITY_AUDIT.md`.

## Scope

Reports should identify the affected package version, input type, impact, and a safe reproduction. FundGraph does not process payments, manage wallets, or automatically donate.
